# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, assume good faith, and remember that scam
victims are people; never mock them or share their personal information.

Report unacceptable behavior privately to the maintainer through
[GitHub](https://github.com/asaphfelix03-beep). Reports are handled confidentially.
